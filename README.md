# 修仙世界

一款适合工作间隙游玩的桌面修仙小游戏。你可以从凡人谋生起步，结识同道、修炼功法，也可以亲自开山、供养门人。

## 这一版可以玩什么

新增飞升台、宗库炼石、护宗大阵与灵脉争夺。山门可扩建九级，门人能任长老、领取资粮并记录个人大事。更新时自动备份并保留现有角色。

## 已有玩家如何更新

游戏内点「检查更新」，看到 0.10.0 后点「立即更新」。游戏会保存当前进度、校验玩家包并启动新版。首次读取旧档会自动备份；Windows 保留上一版程序，回旧版需要其兼容的存档备份。Mac 测试版沿用独立的 Mac 存档目录。

Windows 免安装版请解压全部文件，再运行「修仙世界.exe」。Mac 测试包支持 Apple 芯片和 Intel，尚未经过 Apple 公证。


## 确认官方更新

从 0.9.1 开始，游戏会验证对应平台的更新清单签名。Windows 安装器使用项目自签名证书 **Xiuxian World Player Releases**，系统仍可能显示未知发布者。无需把证书加入本机的受信任根。签名证书的 SHA-256 为 2984EE4662368161D79AD0F8CF0612861E5FE0C38A26202DCCCB35A6D83DBA09。
