# 修仙世界 · 试玩版

《修仙世界》是一款适合在工作间隙轻松游玩的桌面修仙小游戏。0.7.0 加入半圣、大圣、宗门传功和前期备丹，并调整高阶委托与宗门收入。

## Windows

首次安装请运行安装版。已有 0.3.1 或更高版本的玩家，可在游戏内点击「检查更新」，发现新版后点「立即更新」。游戏会保存进度、下载并校验安装包，再启动新版。

新版首次读档会保留进度并备份升级前的存档。安装更新会保留上一版程序。使用 0.6.0 或更早的程序游玩，需要对应的存档备份。

免安装版请先解压全部文件，再运行 `修仙世界.exe`。

## macOS 预发布

测试包支持 Apple 芯片与 Intel，沿用独立的 Mac 测试存档。现有 Mac 测试玩家可在游戏内检查更新，首次游玩请下载并解压测试包。

新版会备份旧档并沿用进度。0.6.0 与升级后的存档格式不兼容，游戏会保护存档并阻止回退。测试包尚未经过 Apple 公证，欢迎真机试玩。
