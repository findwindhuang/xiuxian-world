# 修仙世界 · 试玩版

《修仙世界》是一款适合在工作间隙轻松游玩的桌面修仙小游戏。0.6.0 加入三档灵石、青溪渡旧药田、修行纪事和宗门传承。

## Windows

首次安装请运行安装版。已有 0.3.1 或更高版本的玩家，可在游戏里点击「检查更新」，发现新版后点「立即更新」。游戏会保存当前进度、下载并校验安装包，再启动新版。

新版首次读档会保留原进度并备份升级前的存档。升级后保留上一版程序。0.5.0 和更早版本读取 0.6.0 写入的存档时会保护原文件，使用旧程序游玩需要对应版本的存档备份。

免安装版请先解压全部文件，再运行 `修仙世界.exe`。

## macOS 预发布

测试包支持 Apple 芯片和 Intel，沿用独立的 Mac 测试存档。现有 Mac 测试玩家可在游戏里检查更新，首次游玩请下载并解压测试包。

新版会备份旧档并保留进度。0.5.0 与升级后的存档格式不兼容，游戏会阻止此次回退。测试包尚未经过 Apple 公证，真机安装和更新仍在测试。
