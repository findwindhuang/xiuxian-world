# 修仙世界 · Windows 试玩版

《修仙世界》是一款适合在工作间隙轻松游玩的桌面修仙小游戏。

## 下载

前往 [Releases 下载页面](https://github.com/findwindhuang/xiuxian-world/releases/latest)，下载 Windows 试玩包；将压缩包内所有文件解压到同一文件夹，然后运行 `修仙世界.exe`。

游戏可以离线游玩。发布新版本后，游戏会提示玩家查看更新，玩家可以自行决定是否下载。

## 存档

游戏进度保存在玩家自己电脑的 `%APPDATA%\Godot\app_userdata\xiuxian` 目录。安装新版前，建议先退出游戏并备份这个目录。

本仓库用于提供玩家版下载和版本信息。
