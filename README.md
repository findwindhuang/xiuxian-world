# 修仙世界

一款适合工作间隙游玩的桌面修仙小游戏。从凡人谋生起步，结识同道、修炼功法，或建立自己的宗门。

## 已有玩家如何更新

在游戏内点「检查更新」，看到 0.8.0 后点「立即更新」。游戏会保存当前进度、校验下载的玩家包，再启动新版。首次读取旧存档时自动备份。Windows 保留上一版程序；旧程序需要搭配升级前的存档。Mac 测试版沿用独立的 Mac 存档目录。

Windows 免安装版请解压全部文件，再运行「修仙世界.exe」。Mac 测试包支持 Apple 芯片和 Intel，尚未经过 Apple 公证。
