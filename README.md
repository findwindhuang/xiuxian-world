# 修仙世界 · 试玩版

《修仙世界》是一款适合在工作间隙轻松游玩的桌面修仙小游戏。

## 下载游戏

- [下载 Windows 试玩版](https://github.com/findwindhuang/xiuxian-world/releases/latest)
- [下载 Mac 0.3.3 测试版（ZIP）](https://github.com/findwindhuang/xiuxian-world/releases/download/macos-test-v0.3.3/xiuxian-world-macos-v0.3.3.zip) · [查看测试说明](https://github.com/findwindhuang/xiuxian-world/releases/tag/macos-test-v0.3.3)

## Mac 预发布测试版

Mac 版目前供朋友进行真机测试，支持 Intel 和 Apple 芯片，尚未经过 Apple 开发者公证，首次打开时 macOS 可能提示无法验证开发者。

请先下载 0.3.3 测试包，解压后打开 `xiuxian.app`，然后在游戏中测试更新至 0.3.4 及回退。测试时请只运行一个游戏窗口。

Mac 测试版使用独立测试存档，不会覆盖正式版存档；测试版之间保留进度，但测试进度不会自动转入将来的正式版。

## Windows 试玩版

前往 [Releases 下载页面](https://github.com/findwindhuang/xiuxian-world/releases/latest)，下载名称中带 **setup** 的 Windows 安装程序，双击后按提示安装。完成后，从桌面快捷方式启动游戏。

从 0.3.1 开始，发现新版本后可在游戏中点击“立即更新”：游戏会下载并校验更新、保存进度，安装后重新启动。0.3.0 及更早版本需要先退出游戏，下载并运行一次新版安装程序。

从 0.3.2 开始，游戏内自动更新确认成功后会清理可安全识别的更早程序并保留上一版。条件允许时会创建“修仙世界（上一版）”桌面入口，使用前请先退出当前游戏。存档不参与清理；旧版如果不能读取新版存档，会保护原存档并提示检查备份。

也可下载免安装 ZIP 包，解压全部文件后运行 `修仙世界.exe`。不要同时运行新旧游戏。游戏可以离线游玩；程序尚未进行 Windows 数字签名，请从本页面下载。
