## Windows 试玩版

下载带 **setup** 的安装程序，双击后按提示安装，再从桌面快捷方式启动。0.3.1 及以后版本可在游戏中点击“立即更新”，游戏会保存进度，下载并校验更新，然后重新启动。更早版本请先退出游戏，再运行一次新版安装程序。

升级时会保留现有存档，并在存档格式更新前自动备份。0.5.0 更新后会保留上一版程序；旧版不能直接读取更新后的存档，回退需使用升级前备份，该备份不包含升级后的新进度。

也可在下载页面选择免安装 ZIP 包，解压全部文件后运行 `修仙世界.exe`。请不要同时运行多个游戏窗口。程序尚未进行 Windows 数字签名，请从本页面下载。

## Mac 预发布测试版

Mac 版供朋友进行真机测试，支持 Intel 和 Apple 芯片。测试版沿用独立测试存档，升级时保留现有测试进度并自动备份旧档。0.5.0 的存档格式与 0.4.0 不同，升级后暂时不能在游戏里回退到 0.4.0。测试进度不会自动转入将来的正式版。

Mac 包尚未经过 Apple 开发者认证和公证，首次打开时系统可能提示无法验证开发者。请只从作者提供的官方地址获取。

本仓库只提供玩家版下载和版本信息。
