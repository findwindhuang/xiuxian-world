# 修仙世界 · Windows 试玩版

《修仙世界》是一款适合在工作间隙轻松游玩的桌面修仙小游戏。

## 下载和安装

前往 [Releases 下载页面](https://github.com/findwindhuang/xiuxian-world/releases/latest)，下载名称中带有 **setup** 的 Windows 安装程序，双击后按提示安装。完成后，从桌面快捷方式启动游戏。

0.3.0 及更早版本的玩家，需要先在游戏中存档并退出，再下载并运行一次新版安装程序。游戏会自动读取已有存档，旧档升级时会自动留一份备份，无需手动复制存档。

从 0.3.1 开始，收到新版本提示后，在游戏中点击“立即更新”，即可自动下载并校验、保存进度，然后安装并重启。下载或保存失败时游戏会继续运行。

如果更喜欢免安装版，也可以下载 ZIP 包，解压全部文件后运行 `修仙世界.exe`。请勿同时运行新旧版本；更早版本不一定能读取升级后的存档。

游戏可以离线游玩。程序尚未进行 Windows 数字签名，请从本页面下载。

本仓库用于提供玩家版下载和版本信息。
