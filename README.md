# 修仙世界

## 这一版可以玩什么

宗门与掌门个人资产分账；弟子自费修行，欠俸会影响忠诚，跑商、驻守与危险差事各有时间和成本。主界面可提前查破境材料，地图扩充芦湾药圃、寒泉谷和沉星台。Windows 更新至 0.15.0，Mac 测试包保持 0.14.0。

## 已有玩家如何更新

游戏内点「检查更新」，看到 0.15.0 后点「立即更新」。可直接升级到当前版本，第一次读取旧档会自动备份，原有进度继续保留。新版保存时使用 v49。Windows 0.3.0 及更早的发行版可退出游戏，从当前发行页下载并运行新版安装器。需要回退旧程序时，请使用兼容的旧档备份。

下载页按版本和平台列出安装及便携包。

Windows 免安装版请解压全部文件，再运行「修仙世界.exe」。Mac 测试包支持 Apple 芯片和 Intel，尚未经过 Apple 公证。


## 确认官方更新

从 0.9.1 开始，游戏会验证对应平台的更新清单签名。Windows 安装器使用项目自签名证书 **Xiuxian World Player Releases**，系统仍可能显示未知发布者。无需把证书加入本机的受信任根。签名证书的 SHA-256 为 2984EE4662368161D79AD0F8CF0612861E5FE0C38A26202DCCCB35A6D83DBA09。
